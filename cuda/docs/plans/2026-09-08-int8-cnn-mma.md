# conv5 int8 CNN (mma+ldmatrix) Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Steps use checkbox syntax.
> 完整代码直接实现在 src/ 下各文件(本会话内联执行),本计划锁定接口、公式、算法与验收命令。

**Goal:** RTX 4090 (SM89) 上仅用 mma.sync + ldmatrix(无 cp.async)实现 5 层 3×3 int8 卷积推理,与 CPU int8 参考 bit-exact。

**Architecture:** implicit GEMM,K 排序 `gemm_k = c + C_in_pad*(s+3r)`(通道最内层);内部 NHWC int8;中间层 fused epilogue(bias+requant+ReLU);conv5 直出 fp32 NHWC。三版迭代:naive → smem 分块 → mma+ldmatrix 双缓冲。

**Tech Stack:** CUDA 12.1 + VS2019 14.29 (compiler-bindir), `-arch=sm_89 -std=c++17`,单 exe(gen/test/bench)。

## Global Constraints

- 禁 cp.async;仅 mma.sync / ldmatrix / 普通 LDG+STS
- bit-exact:GPU int8 链路 == CPU int8 链路(整数累加 + 相同 requant 公式)
- requant(中间层): `y = clamp(quant_rn((float)(acc + bias_q[k]) * mult[k]), 0, 127)`
- conv5 输出: `out = (float)(acc + bias_q[k]) * mult[k]`(fp32)
- CPU `quant_rn(x)=(int)lrintf(x)`(最近偶)↔ GPU `__float2int_rn(__fmul_rn(...))`
- H=360 W=796 HW=286560;C_in_real={4,16,32,16,16} C_in_pad={16,16,32,16,16} C_out_real={16,32,16,16,4} C_out_pad={16,32,16,16,8} K_gemm={144,144,288,144,144}
- B 存 [K_gemm × C_out_pad] 行主序,pad 列=0;bias_q/mult 长度 C_out_pad,pad=0
- weights.bin = magic 0xC0FFEE05 + a_scale[5] + 5×{B, bias_q, mult};input.bin = fp32 NCHW
- 乒乓: L0: a0→x0, L1: x0→x1, L2: x1→x0, L3: x0→x1, L4: x1→out
- 源码无注释、ASCII;每 Task 结束 commit
